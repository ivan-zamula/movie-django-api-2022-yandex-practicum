# API кинотеатра на Django (Yandex Practicum, 2022)

[English](README.md) | [Русский](README.ru.md)

Код API кинотеатра на Django и примеры Docker Compose. API включает список фильмов и данные отдельного фильма.

Учебные материалы программы Middle Python Developer Яндекс Практикума.


## Получение кода

```bash
git clone https://github.com/ivan-zamula/movie-django-api-2022-yandex-practicum.git
cd movie-django-api-2022-yandex-practicum
```

## Код и материалы

- [01_docker_compose](01_docker_compose)
- [02_django_api](02_django_api)

## Порядок работы в спринте 2

1. [Docker Compose](01_docker_compose): настройка Nginx, Docker и Django.
2. [Django API](02_django_api): реализация API для выдачи информации о фильмах.

Все части задания сдаются на ревью одновременно.
